# MiniMax

Use MiniMax models with an API key from the MiniMax platform.

## Set up

1. Get an API key from [platform.minimaxi.com](https://platform.minimaxi.com).
2. Open **Settings → Providers → MiniMax**, click **CHANGE** on the **API KEYS** tab, and paste the key.
3. On the **MODELS** tab, click **FETCH**, tick the models you want, and click **Save Changes**.

## Settings

| Field | Environment variable | Notes |
|---|---|---|
| **API Key** | `MINIMAX_API_KEY` |  |

You can set the key's environment variable before starting Suzent instead of
pasting it. It then shows as **Set in env** and can't be changed from the app.
