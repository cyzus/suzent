# DashScope

DashScope uses Alibaba Cloud's OpenAI-compatible endpoint.

**Get your key:** [bailian.console.aliyun.com](https://bailian.console.aliyun.com)

| Field | Description |
|---|---|
| `DASHSCOPE_API_KEY` | Your DashScope API key |

The base URL is built into Suzent as `https://dashscope.aliyuncs.com/compatible-mode/v1`.
