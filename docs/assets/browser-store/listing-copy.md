# Store listing copy

## English

Name: Suzent Browser

Short description: Connect your browser to Suzent using your existing tabs and logins.

### Description

Bring your everyday browser into Suzent.

Suzent Browser connects the Suzent personal AI agent on your computer to the browser profile where you install this extension. Work with your existing web tabs and signed-in sessions, without creating a separate browser profile or enabling a remote-debugging port.

With a paired Suzent app, you can ask your agent to:

- List your web tabs and select a tab to work in.
- Open pages, read page content, click controls, and enter text.
- Follow the selected tab through Suzent's browser preview.

Install the extension, open Settings → Browser in Suzent, select “Use my browser (extension),” and click “Pair browser.” Open the pairing link in the browser where you installed the extension.

You control the connection. Disconnect and forget the pairing in Suzent, or disconnect from the extension popup. Disconnecting leaves your browser tabs open. The extension does not support private/incognito tabs or browser-internal pages.

Requires the Suzent application running on the same computer. AI tasks require a configured model provider; provider charges may apply. This extension is a companion to Suzent, not a standalone AI assistant. Page content and screenshots passed to Suzent may be processed by your configured AI provider. See the privacy policy for details.

Support: https://github.com/cyzus/suzent/issues

Suggested search terms: Suzent, browser assistant, personal AI, tab automation

## 简体中文

名称：Suzent 浏览器

简短描述：让 Suzent 使用现有浏览器标签页和登录状态。

### 详细描述

让 Suzent 进入你日常使用的浏览器。

Suzent 浏览器扩展将电脑上的 Suzent 个人 AI 智能体连接到安装此扩展的浏览器配置。直接使用已有网页标签和登录状态，无需创建独立浏览器配置，也无需开启远程调试端口。

与 Suzent 应用配对后，你可以让智能体：

- 列出网页标签，并选择要操作的标签。
- 打开网页、读取内容、点击控件和输入文字。
- 通过 Suzent 的浏览器预览查看所选标签。

安装扩展后，在 Suzent 的“设置 → 浏览器”中选择“使用我的浏览器（扩展）”，再点击“配对浏览器”。请在已安装扩展的浏览器中打开配对链接。

你可以随时在 Suzent 中断开并忘记配对，或通过扩展弹窗断开连接。断开连接不会关闭浏览器标签。本扩展不支持隐私/无痕标签和浏览器内部页面。

需要在同一台电脑上运行 Suzent 应用。AI 任务需要配置模型提供商，可能产生提供商费用。本扩展是 Suzent 的配套工具，不是独立 AI 助手。传递给 Suzent 的网页内容和截图可能由你配置的 AI 提供商处理，详情请查看隐私政策。

支持：https://github.com/cyzus/suzent/issues
