# 记忆

**主权连续性。** 记忆是主权 AI 智能体安放"自我"的地方。Suzent 的记忆是你磁盘上的 Markdown 文件，而不是某个厂商数据库里的记录，所以你可以阅读、编辑、用 Git 跟踪，并带到另一台电脑上。这也是为什么换模型不会让那个了解你工作的智能体从头开始。请见[什么才是主权智能体？](https://suzent.com/sovereign)。

Suzent 会记住你分享过的事实、你的偏好以及过往对话的上下文。记忆默认开启，无需任何设置。

## 工作方式

**对话过程中。** 每轮对话结束后，Suzent 会挑出值得保留的内容，比如一个偏好、一个项目细节或一件关于你的事，追加到当天的日志里。它保存的是事实，而不是整段对话。

**夜间。** 一个名为 **dream** 的后台任务会读取新的日志，把它们整理成清晰的页面：每个主题一页，合并重复，解决矛盾。白天保存依然很快，整理工作留到之后再做。

记忆分为两类：

| | 内容 | 位置 |
|---|---|---|
| **对话记忆** | 自动收集的关于你的事实 | `/shared/memory/` |
| **笔记本** | 智能体研究并撰写的知识页面 | `/mnt/notebook/` |

笔记本是一个兼容 Obsidian 的知识库，见[笔记本](./llm-wiki.md)。

## 记忆存放在哪里

```text
/shared/memory/
  MEMORY.md              # 智能体每次都会看到的摘要
  archive/
    2026-08-24.md        # 每天一份日志
  persona.md, user.md    # 可编辑的档案笔记
```

这些文件就是真正的记忆，可以用任何文本编辑器打开。搜索索引是根据它们重建的，所以你在这里删掉的内容就真的没了。

<a id="memorymd-is-half-yours"></a>

### MEMORY.md 有一半属于你

`MEMORY.md` 是每次对话都会加载的简短摘要。一行标记注释把它分成两半：

```markdown
<!-- memory:generated - rewritten on consolidation -->
...Suzent 会重写这里的所有内容...
<!-- /memory:generated - notes below this line are kept -->

你在下面写的任何内容都会被永久保留，不会被改动。
```

在标记下方写下你想直接告诉 Suzent 的事。这里的笔记优先于它自己推断出的任何内容，dream 也永远不会覆盖它们。

如果你的 `MEMORY.md` 没有标记（因为它早于这项功能），Suzent 会把整个文件视为你写的，不再自动重新生成。

## 管理记忆

应用中的 **记忆** 面板可以浏览、搜索和删除已保存的内容。

- **想让它忘记某件事**，在面板中删除即可。它会从搜索中永久消失，重建索引后也不会回来。原始的每日日志会把这一行保留为历史记录。
- **想纠正某件事**，直接在对话中说出正确的版本。dream 会替换旧的事实。

<a id="how-memory-is-tidied"></a>

## 记忆如何整理

大约每天一次，dream 会读取尚未处理的日志，并对每条事实做以下四件事之一：

- **确认**：页面里已经有这条，就把计数加一，例如 `(confirmed 12x, last 2026-08-20)`。
- **细化**：页面里的说法比较模糊，就改进措辞。
- **替换**：页面里的内容已经过时，就更正它。
- **新增**：这是新的事实，就记下来。

关于你的事实会放在笔记本的 `3_Personal/` 文件夹，通用知识放在 `2_Wiki/` 下。dream 从不碰当天的日志，中途被打断的整理会重试而不是跳过。

**事实会温和地过期。** 每条关于你的事实都会按类型获得一个复查日期：身份信息永不过期，偏好一年，技术环境六个月，目标三个月，临时情况三周。到期后，dream 会根据最近的对话重新核对。过期从不删除任何内容，只会降低未被确认的事实在搜索中的权重。

没有新内容需要整理时，dream 会转而检查笔记本，寻找矛盾、失效链接、孤立页面和过时知识。

## 设置

在 **设置 → 记忆系统** 中开启或关闭记忆，并选择它使用的模型。dream 使用 **Dream** 模型角色，记忆搜索使用 **向量嵌入** 角色（见[模型角色](../providers.md#model-roles)）。

dream 的运行频率、笔记本的位置等调优项，见[高级记忆设置](./configuration.md)。
