# 记忆

**主权连续性。** 记忆是主权 AI 智能体安放"自我"的地方。Suzent 的记忆是你磁盘上的 Markdown 文件，而不是某个厂商数据库里的记录，所以你可以阅读、编辑、用 Git 跟踪，并带到另一台电脑上。这也是为什么换模型不会让那个了解你工作的智能体从头开始。请见[什么才是主权智能体？](https://suzent.com/sovereign)。

Suzent 会记住你分享过的事实、你的偏好以及过往对话的上下文。记忆默认开启，无需任何设置。

## 工作方式

**对话过程中。** 每隔几轮对话，或者对话停下来大约十分钟后，Suzent 会把上次之后说过的内容读一遍，挑出值得保留的东西，比如一个偏好、一个项目细节或一件关于你的事，追加到当天的日志里。它保存的是事实，而不是整段对话。因为一次读好几轮，你中途改了主意的话，只会保存最后的结论。

关于你的事实，只有你自己说过才会保留；智能体说的或猜的不算。每条保存的事实都带着它出自的原话，你能看到它为什么被保留。任务结果带来的经验，以及智能体在文件或网页里读到的事实，也会保留，并附上发生了什么或出处。定时任务不算，只在今天有用的事也不算。

**夜间。** 一个名为 **dream** 的后台任务会读取新的日志，把它们整理成清晰的页面：每个主题一页，合并重复，解决矛盾。白天保存依然很快，整理工作留到之后再做。

记忆分为两类：

| | 内容 | 位置 |
|---|---|---|
| **对话记忆** | 自动收集的关于你的事实 | `/shared/memory/` |
| **笔记本** | 智能体研究并撰写的知识页面 | `/mnt/notebook/` |

笔记本是一个兼容 Obsidian 的知识库，见[笔记本](./llm-wiki.md)。

## 记忆存放在哪里

```text
/shared/memory/
  MEMORY.md              # 智能体每次都会看到的记忆地图
  archive/
    2026-08-24.md        # 每天一份日志
  persona.md, user.md    # 可编辑的档案笔记
```

这些文件就是真正的记忆，可以用任何文本编辑器打开。搜索索引是根据它们重建的，所以你在这里删掉的内容就真的没了。

<a id="memorymd-is-a-map"></a>

### MEMORY.md 是一张地图

`MEMORY.md` 每次对话都会加载。它是一份简短的链接列表，每个笔记本页面一行，附几个字说明页面里有什么：

```markdown
- [[3_Personal/Preferences]] - 你喜欢的回答方式、工具和格式
- [[2_Wiki/Experience/Release checks]] - 过去发布时出过的问题
```

事实本身放在这些页面里，所以地图始终很小（默认 30 行）。如果文件不存在，Suzent 会根据页面标题起草一份；之后它归你所有，dream 只负责让链接保持最新。

`user.md` 放的是每次对话都需要的内容，比如你的名字、语言和称呼方式。日程和项目进度不属于这里，其他关于你的事实放在 `3_Personal/` 页面里。

<a id="managing-whats-remembered"></a>

## 管理记忆

应用中的 **记忆** 面板可以浏览、搜索和删除已保存的内容。

- **想让它忘记某件事**，在面板中删除即可。它会从搜索中永久消失，重建索引后也不会回来。原始的每日日志会把这一行保留为历史记录。
- **想纠正某件事**，直接在对话中说出正确的版本。dream 会替换旧的事实；如果旧的值曾经是对的，会保留在 **History** 标题下。
- **发现说错了**，直接说（"不对，我从没在巴塞尔住过"）。Suzent 会立刻把它从搜索中隐藏，以后也不会再记下来。
- **dream 拿不准时**，比如两条事实互相矛盾，它会写下一个问题而不是去猜。智能体可能会在合适的时候问你，你的回答会解决它。

<a id="how-memory-is-tidied"></a>

## 记忆如何整理

大约每天一次，dream 会读取尚未处理的日志，并对每条事实做以下四件事之一：

- **确认**：页面里已经有这条，就把页面的 `confirmed` 计数加一。经常重复的事实在搜索中排名更高。
- **细化**：页面里的说法比较模糊，就改进措辞。
- **替换**：页面里的内容已经过时，就更正它。
- **新增**：这是新的事实，就记下来。

每个页面都会写明自己是哪一类：关于你的事实、过往工作的经验或通用知识。dream 会按笔记本 `schema.md` 的说明放置每一类；没写的话，就放在同类页面旁边，或者放进你已有的最合适的文件夹。新笔记本里，关于你的事实放在 `3_Personal/`，经验放在 `2_Wiki/Experience/`，知识放在 `2_Wiki/` 下。你的文件夹不必和默认一致：dream 从不修改 `schema.md`，也从不新建带编号的顶层文件夹。想指定位置，就在 `schema.md` 里写明每一类放哪里。dream 从不碰当天的日志，中途被打断的整理会重试而不是跳过。它改动过的内容都会列在笔记本的 `log.md` 里。

**事实会温和地过期。** 每条关于你的事实都会按类型获得一个复查日期：身份信息永不过期，偏好一年，技术环境六个月，目标三个月，临时情况三周。到期后，dream 会根据最近的对话重新核对。过期从不删除任何内容，只会降低未被确认的事实在搜索中的权重。

没有新内容需要整理时，dream 会转而检查笔记本，寻找矛盾、失效链接、孤立页面和过时知识。

## 设置

在 **设置 → 记忆系统** 中开启或关闭记忆。它使用的模型在 **设置 → 模型角色** 中设置：dream 使用 **Dream** 角色，挑选事实使用 **记忆提取** 角色，记忆搜索使用 **向量嵌入** 角色（见[模型角色](../../04-models/model-roles.md)）。

dream 的运行频率、笔记本的位置等调优项，见[高级记忆设置](./configuration.md)。

<a id="checking-and-tidying-your-memory-files"></a>

## 检查和整理记忆文件

记忆变乱时，有两个命令可以帮忙：

```bash
suzent memory lint
```

```bash
suzent memory cleanup
```

`lint` 列出不符合上述规则的地方：`MEMORY.md` 里写的是事实而不是链接、`user.md` 过长、页面过大。`cleanup` 会把建议修改后的版本写在记忆旁边供你查看，从不改动你的文件。见[命令行](../../07-reference/cli.md#memory)。
