# 工具

工具是智能体可以执行的动作：搜索网页、读写文件、运行命令、操作浏览器等。你决定每个对话可以使用哪些工具，任何会改动你的文件或外部世界的操作都会先征求你的同意（见[权限与审批](./human-in-the-loop.md)）。

## 开关工具

在对话设置中打开工具选择器。工具按能力分组：点击分组标题可以整组开关，也可以逐个勾选。

默认已开启一组常用工具：网页搜索、文件、命令、任务与目标、图像、子智能体和记忆搜索。你不必一开始就全部打开。当任务需要某个未开启的工具时，智能体可以自行为当前对话开启它。

## 可用能力

| 能力 | 智能体能做什么 |
|---|---|
| **文件系统** | 读取文件（包括 PDF、Word、Excel、PowerPoint 以及图片中的文字），创建和编辑文件，按名称或内容搜索。它能访问哪些文件夹，见[工作区与沙盒](../filesystem.md)。 |
| **Shell** | 运行命令，或在后台启动长时间运行的命令，稍后再查看结果。 |
| **网页** | 搜索网页、读取页面，并操作浏览器（它自己的或你的）。见[浏览器](./browser.md)。 |
| **任务与目标** | 把工作拆成可跟踪的任务，跨多轮持续推进一个[目标](../automation.md#goal-mode)，并为自己安排后续跟进。 |
| **编排** | 加载[技能](../skills.md)，把工作交给[子智能体](#sub-agents)。 |
| **交互** | 向你提出一个具体问题，或在侧边栏和聊天中展示表格、表单、卡片和按钮。你的点击和表单回答会直接发回给智能体。 |
| **创作** | 生成和编辑图像、制作视频、朗读文字，以及通过你的[聊天应用](../../05-chat-apps/README.md)发送消息。见[下文](#images-video-and-speech)。 |
| **记忆与回溯** | 搜索它记住的内容，找到相关的过往对话。见[记忆](../memory/README.md)。 |

## 网页搜索

网页搜索开箱即用，默认使用 DuckDuckGo。如果想要更私密或更稳定的结果，可以自建 [SearXNG](https://docs.searxng.org/) 实例，并在 `.env` 文件中设置 `SEARXNG_BASE_URL`，Suzent 会自动使用它。

## 后台命令

耗时较长的命令（比如构建或开发服务器）可以在后台运行，你可以继续聊天。**后台任务** 侧边栏会显示每条命令的实时输出、退出码和停止按钮，子智能体也显示在这里。后台命令结束时，智能体会收到通知并接着处理，即使你已经在聊别的。

<a id="sub-agents"></a>

## 子智能体

智能体可以为任务中相对独立的部分启动一个辅助智能体，既可以等待它完成，也可以让它在后台运行。辅助智能体会显示在 **后台任务** 侧边栏中。智能体还可以查看、给同一项目中的其他对话发消息或停止它们，也可以联系[已配对设备](../nodes.md)上的智能体。

<a id="images-video-and-speech"></a>

## 图像、视频和语音

这些工具需要各自的模型。先在 **设置 → 模型角色** 中分配（见[模型角色](../../04-models/model-roles.md)），再在工具选择器中开启对应工具。

**图像。** 让智能体生成图片时，它会使用你的 **图像生成** 模型。要修改已有图片，附上图片并描述你想要的改动，这会使用 **图像编辑** 模型。结果保存在工作区的 `images` 文件夹中。

**视频。** 分配 **视频生成** 模型后，可以这样说："生成一段 8 秒的横屏视频，内容是雾气在森林中流动。"视频是付费且较慢的任务：智能体会提交任务、定期查看进度，并在聊天中展示完成的视频。要让一张图片动起来，附上图片并说明用它作参考。

**语音。** 智能体可以用两种方式朗读文字，在 **设置 → 语音与音频** 中配置：

- **系统** 使用你设备上已安装的语音，不需要模型或 API 密钥。
- **API** 使用你的 **语音合成** 模型，音质更好，并会保存音频以便重播。

新生成的语音会自动播放。如果你更想手动点播放，可以在同一设置中关闭 **自动播放工具新生成的语音**。

<a id="mcp-servers"></a>

## MCP 服务器

Suzent 可以使用任何 [MCP](https://modelcontextprotocol.io/) 服务器提供的工具。打开 **设置 → MCP 服务器**，填写服务器的命令（或 URL），点击 **测试**，然后为需要的对话启用它。
