# 工具

工具是智能体可以执行的操作：读写文件、运行命令、搜索网络、操作浏览器等等。你可以决定每个对话能用哪些工具，凡是会修改你的文件或影响外部世界的操作都会先征求你的同意（见[权限与审批](./human-in-the-loop.md)）。

<a id="whats-available"></a>

## 有哪些工具

| 分组 | 智能体能做什么 | 详细说明 |
|---|---|---|
| **Filesystem** | 读取文件（包括 PDF 和 Office 文档），写入和编辑文件，按名称或内容查找文件。 | [文件](./files.md) |
| **Shell** | 运行命令，或在后台启动耗时较长的命令并稍后查看。 | [命令](./shell.md) |
| **Web** | 搜索网络、阅读网页、操作浏览器。 | [网络搜索与网页](./web.md)、[浏览器](./browser.md) |
| **Orchestration** | 把工作交给辅助智能体，加载[技能](../skills.md)。 | [子智能体](./sub-agents.md) |
| **Tasks & goals** | 跟踪任务，跨多轮对话追求一个目标，为自己安排后续跟进。 | [任务与规划](./tasks.md) |
| **Interaction** | 向你提出具体问题，或展示你可以直接作答的表格、表单和按钮。 | [提问、画布与消息](./interaction.md) |
| **Creative** | 生成和编辑图片、制作视频、朗读文字，并通过你的聊天应用发送消息。 | [图片、视频与语音](./media.md) |
| **Memory & recall** | 搜索它记住的内容，查找过去的对话。 | [记忆](../memory/README.md) |

你添加的 [MCP 服务器](./mcp.md)提供的工具也会和这些工具一起出现。

<a id="choosing-tools-for-a-chat"></a>

## 为对话选择工具

点击 **打开侧栏** 打开右侧边栏，切换到 **工具** 标签页。勾选一个分组可以一次开关其中所有工具，也可以逐个勾选。

默认已开启一组常用工具：网络搜索、文件、命令、任务与目标、图片生成与编辑、子智能体和记忆搜索。**Skill** 和 **Ask Question** 始终开启。

不必一开始就把所有工具都打开。当任务需要一个关闭的工具时，智能体可以自己找到它，并在当前对话中开启。这类工具会显示 **AI** 标记，如果你不想用，可以点 **停用** 关掉。智能体自己开启的工具仍会照常征求你的同意。

命令类工具和 **Social Message** 例外：关闭后会显示 **已关闭**，智能体无法自行重新开启。
