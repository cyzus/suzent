# Suzent 是什么？

Suzent 是一个**主权 AI 智能体**：一个身份、记忆、技能、工作区和运行环境都由你掌控的个人 AI 智能体。模型可以替换，平台终会更迭，而智能体的延续性属于你。

## "主权"是什么意思

主权 AI 智能体由用户拥有和治理，而不是由模型提供商或平台掌控：

- **主权心智。** 模型是引擎，不是自我。从一个模型换到另一个模型，它仍然是那个了解你工作的智能体。
- **主权权力。** 它只在你设定的权限范围内行动，任何你没允许的事都会先问你。
- **主权容器。** 它运行在你的电脑上，只能访问你交给它的文件夹和设备。
- **主权连续性。** 它的记忆、技能和设置都是普通文件，你可以阅读、编辑、备份，并带到新电脑上，而你的密钥留在原地。

"主权 AI"也常用于国家层面，指由国家掌控的模型、数据和算力。主权智能体把同样的理念落到个人身上。完整定义以及判断任何智能体的五个问题，请见[什么才是主权智能体？](https://suzent.com/sovereign)。

## 它能做什么

| | |
|---|---|
| **使用任何模型** | GPT、Claude、Gemini、DeepSeek，通过 Ollama 运行的本地模型等，随时切换。 |
| **记住你** | 跨对话记住你的偏好和项目，以你拥有的 Markdown 文件保存。 |
| **把事办成** | 搜索网页、处理文件、运行代码、操作浏览器，遇到有风险的步骤会先征求你的同意。 |
| **按计划工作** | 每日报告、提醒、定期检查和长期目标。 |
| **学习新技能** | 可安装、分享或自己编写的 `SKILL.md` 技能包。 |
| **随处可用** | 桌面应用、手机、Telegram、Slack、Discord、飞书和微信。 |
| **连接你的设备** | 配对其他电脑和手机，或连接其他智能体。 |

## 整体结构

```text
你 ──► Suzent（在你的电脑上）
          ├── 你选择的任意 AI 模型
          ├── 记忆和笔记本（Markdown 文件）
          ├── 工具（网页、文件、命令、浏览器）
          ├── 技能
          ├── 自动化（定时任务、心跳、目标）
          └── 聊天应用和已配对设备
```
