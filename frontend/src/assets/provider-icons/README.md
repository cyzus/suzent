Provider logos bundled with the app, so they render offline and under the
desktop CSP, which blocks off-origin images.

Source: [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons)
1.101.0 (MIT). The mono variants, with `currentColor` replaced by white and the
fixed `1em` size removed, so they sit on the provider color like before.

`litellm.png` is LiteLLM's own logo, taken from the litellm 1.81.13 wheel
(`proxy/_experimental/out/assets/logos/litellm_logo.jpg`) and cut to a circle.
It is full colour, so its tile uses the circle's blue instead of a brand color.
