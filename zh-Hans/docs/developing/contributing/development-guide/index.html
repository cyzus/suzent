Quick Start

Get SUZENT running in development mode in under 2 minutes.

suzent start --dev starts the debug backend, then runs the Electron shell in apps/desktop on the Vite dev server, so frontend edits hot-reload in the window. It installs the frontend/ and apps/desktop/ npm dependencies when they are missing. suzent stop ends both.

Plain suzent start in a source checkout runs the same shell on the built web UI (frontend/dist) instead; build it with npm run build in frontend/ and then in apps/desktop/. For a headless debug backend only, use uv run suzent serve --debug.

To update an existing development checkout, run:

This fast-forwards the current branch from its configured upstream, installs the Python and npm dependencies from the lockfiles, and rebuilds the web UI and the desktop shell. Suzent detects that this is a source checkout and selects the development channel automatically.

CLI development updates require a clean working tree and a configured upstream. Untracked files, unfinished Git operations, detached HEAD, or divergent history must be handled manually. Updates do not switch branches or stash your work.

uv sync --all-extras installs every optional dependency group (chat apps, camera and dev; equivalent to the all extra). For a minimal runtime without dev tooling, use uv sync; chat apps and the camera install their packages when they are set up, as in a normal install.

To set up a fresh developer checkout with the setup script instead, run it with SUZENT_DEV_SETUP=1 and --source; it installs the npm dependencies and builds the web UI and the desktop shell.

Prerequisites

  • Node.js 20.x or higher
  • Python 3.12 or higher, managed with uv

The desktop shell is Electron, so developing it needs no Rust toolchain or platform webview packages. Rust is only needed to work on the setup window (apps/desktop-setup), the Microsoft Store helper (apps/desktop/store-cli) or the legacy Tauri code (src-tauri, apps/suzent-installer).

Local Ports

Default local endpoints for development:

  • Backend API: http://127.0.0.1:25314
  • Frontend dev server: http://127.0.0.1:18080 (server.port in frontend/vite.config.ts, and SUZENT_DEV_URL for the shell)

Architecture Notes

Suzent uses pydantic-ai directly for provider execution, streaming, history processing, and deferred tool discovery, but keeps product-specific wrappers where they preserve local behavior. Tools still route through Suzent's registry, permission engine, sandbox/path policy, frontend events, and persisted replay contracts before execution.

Do not replace shell, filesystem, MCP, web, image, or skill behavior with a native provider primitive unless the replacement preserves cross-provider fallback, permission policy, cancellation, persisted tool-call replay, and the existing frontend event contract.

Logo standard

Use SuzentLogo for UI placements:

className controls size; interactive defaults to false and enables cursor-following eyes. Use 28 px (h-7 w-7) in headers and 64 px or larger on splash screens. Avoid interactive instances in large lists.

The canonical 24 × 24 geometry is a black rounded square (rx=4) with white 5 × 5 eyes at (5,8) and (14,8), each with rx=1.5. Change the component first, then synchronize frontend/public/favicon.svg and the RobotFace primitive in frontend/src/components/chat/RobotAvatar.tsx. RobotAvatar retains its own primitive for its animation variants. Do not inline new copies of the logo or add an outer white border.

Troubleshooting

Backend not responding

Verify backend is running:

Should return JSON configuration.

Frontend shows connection errors

  1. Verify backend is running: curl http://localhost:25314/config
  2. Open DevTools in the window and check the console for the actual error
  3. Ensure CORS is working (should be by default)

Changes not appearing

  • Frontend changes: Should auto-reload. Try a hard refresh (Ctrl+Shift+R).
  • Backend changes: Restart the backend (Ctrl+C, then restart).
  • Desktop shell changes: Close the window and run npm run dev again.

suzent start says no desktop build was found

Run npm install and npm run build in frontend/ and then in apps/desktop/, or use suzent start --dev.
