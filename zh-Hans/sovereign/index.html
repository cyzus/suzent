什么才是主权智能体？

主权不只是把智能体运行在自己的电脑上，而是你能够拥有它的记忆、选择它的智能、治理它的行动，并让它的身份跨越任何模型和平台继续存在。

谁应该拥有这些权力？Suzent 的答案始终是：你。

定义

什么是主权 AI 智能体？

主权 AI 智能体（sovereign AI agent）是指身份、记忆、技能、工作区和运行环境由使用者本人拥有和治理，而不是由模型提供商或平台掌握的 AI 智能体。它的持久状态保存在你可以阅读、编辑、版本管理和迁移的文件中；它的行动运行在你定义的权限边界内；更换底层模型也不会重置这个了解你工作的智能体。Suzent 就是这一定义的开源、本地优先实现。

“主权 AI”这个说法也被用在国家层面，指国家掌控的模型、数据和算力。主权智能体把同样的理念放到个人尺度：一个智能体的主权，属于运行它的那个人。

四个必要条件

I

主权心智

模型是引擎，而不是自我。更换模型提供商时，定义智能体的记忆、技能、上下文和工作区仍然属于你。

模型 ≠ 身份
II

主权权力

自主行动必须服从你的规则。权限、作用域、审批、沙箱和活动记录，让权力边界明确且可检查。

行动 ⊆ 你的规则
III

主权容器

智能体运行在你控制的领域。文件夹、工作区、服务和连接设备都由你主动授予，而不是被平台默认接管。

运行环境 ∈ 你的领域
IV

主权连续性

记忆、技能和配置可以迁移，凭证留在本地。即使提供商、模型或设备消失，智能体也不会随之消失。

自我 > 平台

主权测试

所有权必须能够被检验。

在称一个智能体为“主权智能体”之前，先问五个问题：

  1. 01

    我能否检查、编辑、版本管理和删除它的记忆？

    在 Suzent 中，记忆是保存在你自己磁盘上的追加式 Markdown 文件。你可以用任意编辑器打开、用 Git 管理版本，也可以随时删除，无需任何厂商许可。搜索索引服务于这些文件，并且可以从文件重建。

  2. 02

    我能否更换模型，而不重置它的身份？

    身份存在于记忆、技能、上下文和工作区中，而不在模型里。在 GPT、Claude、Gemini、DeepSeek 或本地模型之间切换，都不会影响这个了解你工作的智能体。

  3. 03

    我能否定义、审批并审计它被允许执行的行动？

    工具调用会经过你设定的权限模式，由人工审批和作用域规则决定哪些行动可以从推理跨越到真实执行。

  4. 04

    我能否迁移它的状态，而不导出自己的凭证？

    可迁移的智能体状态与设备本地的密钥分开同步，因此换一台机器时不必把 API 密钥一起带走。

  5. 05

    如果提供商消失，这个智能体还能继续存在吗？

    定义这个智能体的一切，本来就是你手中的文件。提供商关停让你失去的是一个 API 密钥，而不是一个智能体。

如果答案取决于厂商是否许可，这个智能体就还不完全属于你。

不是承诺，而是证据
